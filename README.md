# Digital Systems Electronics Labs (2024–2025)

VHDL-based labs implemented using Quartus Prime and ModelSim on the DE1-SoC board.  
Includes multiplexers, 7-segment decoders, counters, adders, multipliers, and FSMs.

## Labs Overview
- **Lab 1:** Multiplexers (2-to-1, 5-to-1), LED control
- **Lab 2:** 7-Segment Display with Multiplexing and Binary to Decimal Conversion
- **Lab 3:** 4/16-bit Adders (Ripple, Carry-Bypass, Carry-Select), Array Multiplier
- **Lab 4:** FSMs, Counters, Timers, Reaction Time Display
- **Lab 5:** Sequence Detection FSM, HELLO Display Scroller

## Tools
- VHDL
- Quartus Prime
- ModelSim
- DE1-SoC FPGA Board
